# Neon-Survivor-2030
Shooter de supervivencia top-down ambientado en el año 2030, donde una plaga zombie de origen cibernético ha devastado la ciudad. Controlas a un soldado ermitaño equipado con armamento plasma, enfrentándote a oleadas interminables de mutantes (zombies normales, corredores rápidos y tanques blindados) mientras recoges experiencia.
